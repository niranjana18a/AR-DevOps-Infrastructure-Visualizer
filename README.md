# AR DevOps Infrastructure Visualizer with Live CI/CD Monitoring

## Project Description

An Augmented Reality based system for visualizing DevOps infrastructure
and monitoring CI/CD pipelines in real time.

## Main Technologies

- Unity
- AR Foundation
- C#
- Python
- FastAPI
- GitHub
- Jenkins
- Docker
- Kubernetes
- Prometheus
- Grafana

## Main Modules

1. AR Infrastructure Visualization
2. AR Interaction
3. FastAPI Backend
4. CI/CD Monitoring
5. Docker and Kubernetes Monitoring
6. Prometheus Monitoring
7. Alerts and Notifications
8. AR Dashboard
